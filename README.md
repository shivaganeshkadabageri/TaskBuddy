# TaskBuddy – Task Management Application

TaskBuddy is a React-based task management application designed to help users organize tasks, track progress, and manage daily activities efficiently.

## Features

- Create, update, and manage tasks.
- Search and filter tasks by status, priority, and category.
- Sort tasks for better organization.
- Track task completion and progress.
- View completed tasks and task history.
- Organize tasks using a calendar and Kanban board.
- View task analytics and progress.
- Manage user profiles and application themes.
- Save tasks and preferences using browser local storage.

## Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Vite
- Local Storage

## Key Highlights

- Built reusable React components for modular development.
- Implemented task filtering, searching, and sorting.
- Used browser Local Storage to persist tasks and user preferences.

## Future Enhancements

- Add user authentication and cloud-based data storage.
- Enable synchronization across multiple devices.
